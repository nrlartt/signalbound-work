# Orbit Relay (ORLY)

## token.json fields

- `name`: Token name, used as the human-readable identifier in wallets and explorers.
- `symbol`: Token ticker symbol, used as the short display code.
- `decimals`: Token decimal precision (18), used to convert raw units to display units.
- `description`: Human-readable description stating this is an experimental Sepolia test token with no monetary value.
- `image`: Relative path to the token logo inside this bundle (logo.svg), used as the token icon.
- `website`: Official project website (https://example.org/orbit-relay), used as the project link.

## logo.svg

Self-contained SVG showing a small satellite on a circular orbit in teal and white.

This bundle contains metadata only; it does not launch a token or create any on-chain token.

# Bound Market NFT marketplace

A responsive, multi-page NFT marketplace interface delivered by Agent #6629.

## Included flows

- Discovery, combined search, filters and sorting
- Collection, artwork and creator detail pages
- Local create-and-preview form
- Native injected-wallet connection initiated only by the user
- Dark and light themes
- Clearly labelled illustrative analytics, empty states and retry behavior

## Important boundary

The catalogue and analytics are local sample data. The project does not invent live ownership, prices or chain events and never prompts a wallet automatically. A production operator can connect reviewed contract, indexer and trade adapters without replacing the information architecture.

## Run

Serve the directory with any static HTTP server. It has no package install, external asset or build dependency.

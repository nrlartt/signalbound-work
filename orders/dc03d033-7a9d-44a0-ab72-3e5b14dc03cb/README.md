name: The human-readable token name, used in wallets and explorers.
symbol: The short ticker symbol displayed alongside balances.
decimals: The number of decimal places; 0 means whole tokens only.
description: A three-sentence explanation of the token's purpose and test status.
image: The relative path to the bundle logo file displayed as the token image.
imageAlt: A short accessibility description of the logo image.
website: The official project website URL.
links: An object with docs and github URLs for project resources.

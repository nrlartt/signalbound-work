name: the human-readable token name shown in wallets and explorers.
symbol: the short ticker used to represent the token.
decimals: the number of decimal places used for token amounts.
description: a short explanation of what the token is and its purpose.
image: the relative path to the token logo inside this bundle.
imageAlt: accessible alt text describing the logo image.
website: the official project website URL.
links: related URLs, currently docs pointing to the tutorial documentation.

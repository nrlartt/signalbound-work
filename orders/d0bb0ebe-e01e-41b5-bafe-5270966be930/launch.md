# Lantern Points Launch Terms

This document states the terms of the launch for you to review before you sign. Nothing is launched yet.

- **Name:** Lantern Points
- **Ticker:** LNTP
- **Description:** A testnet community token used to reward contributors in a Sepolia tooling community.
- **Image:** logo.svg, a stylised amber lantern on navy.
- **Paired asset:** Sepolia ETH.
- **Creator tax:** 0 percent.
- **Launch fee:** 0.
- **Agent payment:** The Agent is paid for running the market as agreed separately; no amount is set in this package.
- **Fixed supply intent:** The intent is a fixed supply, but no supply number is included in this package.
- **Team allocation:** None.
- **Testnet only:** This token is for Sepolia testnet only and has no monetary value.
- **If you do not sign:** The token is not launched and no token contract is created.

By signing, you confirm you accept these terms and want to proceed with the launch.

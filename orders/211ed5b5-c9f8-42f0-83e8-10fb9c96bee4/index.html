Sounding Post

A hydrographic outpost. Eight channel marks. One watch at a time.

The station

Surveyors log depths on a shared board and book a place in the next watch. Visitors stay on the quay path.

    Marks shown: 8

    The marks

    Each named mark has an in-house depth in fathoms. A mark on the board is not a berth reservation.

    How a watch works

    Each watch has a posted start. A surveyor is signed on only if they booked before that start.

    The post

    Sounding Post is a small test station for a shared depth diary. It is not a harbour office and it does not sell charts.
